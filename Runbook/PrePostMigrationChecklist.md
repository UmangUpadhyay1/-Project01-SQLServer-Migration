# Migration Checklist

## Before Migration

- [x] Full backup completed
- [x] Backup verified
- [x] Row counts captured
- [x] Target instance available

## During Migration

- [x] Full restore completed
- [x] Differential restore completed

## After Migration

- [x] Row counts validated
- [x] Differential data validated
- [x] DBCC CHECKDB completed
- [x] Migration approved
